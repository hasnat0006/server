Regenerate Blockchain Build + Deployment Files

1) Open terminal and go to blockchain module:
cd /home/hasnat0006/Documents/server/block_chain_module

2) Compile contracts (recreates artifacts/ and cache/):
npm run compile

3) Start local Hardhat node in Terminal 1:
npm run start

4) In Terminal 2, deploy the contract (recreates deployment-info.json):
npm run deploy

Notes:
- Keep Terminal 1 (node) running while deploying.
- If deployment fails, ensure node is running at http://127.0.0.1:8545
- Optional clean rebuild:
  npm run clean
  npm run compile
